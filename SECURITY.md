# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **[Report a vulnerability](https://github.com/syedalijaseem/officehand/security/advisories/new)** form (Security → Advisories). Don't open a public issue.

Include what you found, the steps to reproduce it, and the impact you expect. You'll get an acknowledgment within 3 business days, and we'll keep you updated until it's fixed.

## Scope

In scope: this repository's code, including the API, the Angular app, the Docker image and the CI configuration.

Out of scope: the fictional sample data (it contains intentional prompt-injection and fraud examples for testing), and third-party services such as Google APIs, Gemini and Fly.io.

## Supported versions

The project is pre-1.0. Only the latest commit on `main` receives fixes.
